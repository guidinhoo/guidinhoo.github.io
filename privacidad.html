Uso de datos

Política de privacidad

Última actualización: 21 de octubre de 2026.

Esta política describe el tratamiento de datos realizado por la aplicación privada Integra Recursos · Resumen B2B, administrada por Guido Leiva. Contacto: leivaguido1@gmail.com.

Acceso a Google

Con el consentimiento del titular, la aplicación obtiene un permiso OAuth de Gmail limitado a enviar correo (gmail.send). Utiliza la dirección de la cuenta emisora, una credencial de autorización y los identificadores de los mensajes enviados. No solicita acceso para leer el buzón, los contactos, los archivos de Drive ni el calendario.

Finalidad

El acceso se utiliza exclusivamente para enviar el resumen operativo B2B al destinatario configurado por el operador y registrar el resultado del envío para prevenir duplicados. No se usa para enviar campañas ni mensajes a prospectos.

Datos comerciales

La aplicación procesa registros de empresas del CRM autorizado y evidencia pública sobre esas empresas. Los datos y los informes comerciales permanecen en el entorno privado del operador. El proveedor de búsquedas recibe el nombre y la localidad de las empresas; no recibe credenciales de Google, contenido del buzón ni notas privadas del CRM.

Servicios que intervienen

Google procesa la autorización y el envío mediante Gmail API. GitHub aloja la ejecución y el almacenamiento privado. HubSpot conserva los registros comerciales y Tavily proporciona resultados de búsqueda. Solo se transmite a cada servicio la información necesaria para su función. Durante la autorización inicial puede utilizarse la herramienta oficial Google OAuth Playground para obtener el permiso, con aprobación del titular.

Almacenamiento, conservación y seguridad

Las credenciales de Google se guardan como secretos cifrados en el repositorio privado del operador. El registro operativo conserva identificadores y estados de envío para impedir repeticiones. Los informes y el historial comercial se conservan hasta que el operador determine su eliminación; no se publican en esta página. El titular puede revocar el acceso a Google sin eliminar automáticamente los mensajes que ya se hayan enviado o sus copias en Gmail.

Uso limitado de datos de Google

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de Datos del Usuario de los Servicios de API de Google, incluidos sus requisitos de uso limitado. La aplicación no vende esos datos, no los utiliza para publicidad ni para entrenar modelos de inteligencia artificial.

Revocación y solicitudes

El titular puede retirar el permiso desde las conexiones de su Cuenta de Google. Para solicitar acceso, corrección o eliminación de los datos administrados por esta aplicación, puede escribir al contacto indicado al comienzo de esta política. La eliminación del registro de entregas requiere revisión para evitar reenvíos no deseados.

Esta página pública

Esta página es estática, no tiene formularios, publicidad ni analítica agregada por la aplicación. GitHub Pages procesa los datos técnicos de las visitas conforme a la política de privacidad de GitHub.
